## 二、本机路径适配（重要）

原实现把存档目录写死为 `F:\桌宠`、DSH 工作目录写死为 `F:\李智梅党建工作材料`。本机没有 F 盘，会直接失败。现已改为**运行时动态解析**：

| 用途 | 优先顺序 |
| --- | --- |
| 存档根目录 `Resolve-PetStore` | `config.storage.dir` → 有 F 盘用 `F:\桌宠` → 否则 `%USERPROFILE%\.dsh\fish-pet\存档` |
| DSH 工作目录 `Resolve-DshCwd` | `config.dsh.cwd` → 有 `F:\李智梅党建工作材料` 用它 → 否则「我的文档」 |

本机实测结果：

```
存档根目录 : C:\Users\eric8\.dsh\fish-pet\存档
DSH 工作目录: C:\Users\eric8\Documents
```
